# Dating Click

Локальная панель и отдельные фоновые процессы для автоматических лайков анкетам. Node.js 20+, Linux, Chrome или Chromium. Отправка сообщений не реализована.

## Запуск

```bash
npm install
# Если Google Chrome не установлен:
npx playwright install chromium
npm start
```

Открыть **http://127.0.0.1:3210**. Для другого порта: `PORT=3211 npm start`.

1. Нажать «Войти и запустить» у платформы. Откроется отдельное окно браузера **на компьютере, где запущен сервер**.
2. Войти обычным способом, пройти необходимые проверки и открыть ленту анкет. Пароль вводится на самом сайте.
3. Если кнопка имеет стандартную подпись «Нравится»/«Лайк»/«Like»/«Симпатия», она распознаётся автоматически. В остальных случаях нажать в окне сайта «Выбрать кнопку лайка», затем указать реальную кнопку. Этот клик перехватывается и не отправляется сайту.
4. После распознавания анкеты окно закрывается автоматически; та же сессия открывается в фоновом Chromium. Панель покажет «Работает в фоне».

Панель, вкладку и сервер управления можно закрывать: worker является независимым процессом. Чтобы остановить его, запустить панель снова и нажать **«Остановить»**. Компьютер должен быть включён и не спать. После выхода из пользовательской сессии или перезагрузки потребуется запустить панель и нажать **«Продолжить»**. Запуск при загрузке ОС не установлен.

Для входа необходима графическая сессия. Для сервера без рабочего стола нужен удалённый рабочий стол; вход через браузер на другом компьютере не передаёт серверу авторизацию автоматически.

## Платформы и ограничения

| Платформа | Подключение |
| --- | --- |
| VK Знакомства | Начальный адрес `https://vk.ru/dating`, включая работу в iframe мини-приложения. Войти и открыть ленту. |
| Mamba | Начальный адрес `https://www.mamba.ru/`. Войти и открыть ленту. |
| Twinby | Браузерный вход не подтверждён. `https://twinby.ru/` — сайт приложения; адрес ленты намеренно не подставляется. Если у вас есть рабочая веб-версия, указать её HTTPS-адрес в настройках. Мобильное приложение, Android-эмулятор и iOS этим проектом не управляются. |

**На реальных аккаунтах эти интеграции не проверены.** Это браузерный адаптер с настройкой кнопки и контейнера анкеты, а не интеграция с официальными API. Изменения сайта могут потребовать повторного выбора кнопки. Поддержка Twinby через мобильное приложение требует отдельного адаптера и устройства/эмулятора.

Официальные страницы: [VK Знакомства](https://vkdating-app.ru/legal/ru/terms/), [Mamba](https://www.mamba.ru/), [Twinby](https://twinby.ru/faq). Реализованный способ хранения сессии: [Playwright persistent context](https://playwright.dev/python/docs/api/class-browsertype#browser-type-launch-persistent-context).

## Работа в фоне

- По умолчанию пауза между попытками — 15 секунд, максимум — 100 попыток за местные календарные сутки. Можно изменить в настройках остановленной платформы.
- Бюджет попыток списывается **до** клика и хранится на диске. Сбой, неуспешный клик или перезапуск не возвращают попытку.
- Счётчик в панели означает смену анкеты после клика. Он не подтверждает принятие лайка сервером платформы.
- До клика проверяется стабильность содержимого анкеты. После клика ожидается новая анкета. Если она не появилась за 10 секунд, процесс останавливается; повторных кликов в прежнюю карточку не происходит.
- Последние 10 000 отпечатков обработанных карточек хранятся между запусками. При повторном отпечатке работа приостанавливается. Отпечаток выводится из ID, текста и изображений карточки; это эвристика, а не проверенный ID аккаунта сервиса.
- Если контейнер анкеты не определяется, указать его CSS в настройках. Рекомендуется контейнер конкретной карточки, содержащий фото и данные человека, без панели уведомлений и счётчиков.
- Доступен один процесс на платформу. Перед повторным входом остановить текущий процесс и дождаться завершения.
- При видимой капче, диалоге оплаты/лимита, пропавшей кнопке или ошибке процесс останавливается. Полноэкранная проверка без известной разметки определяется через недоступность кнопки или отсутствие смены карточки. Проверки входа выполняются вручную; покупки и суперлайки автоматически не выбираются.

## Хранение и диагностика

Все рабочие данные — `.data/<платформа>/`: отдельный профиль браузера, cookies и sessionStorage для переноса авторизации между окнами, конфигурация, счётчики, отпечатки, события и `worker.log`. Данные исключены из Git. Папки создаются с правами `0700`, JSON и журналы — `0600`. Профиль и файлы авторизации содержат действующую сессию входа; не передавайте `.data` другим людям.

Панель слушает только `127.0.0.1`, проверяет Host/Origin, требует секрет страницы для изменений и не отдаёт содержимое профилей. Это приложение для одного локального пользователя. Не публикуйте порт через reverse proxy без отдельной аутентификации.

Переменные среды:

| Переменная | Назначение |
| --- | --- |
| `PORT` | Порт панели, по умолчанию 3210 |
| `DATING_CLICK_DATA` | Другой каталог рабочих данных |
| `DATING_CLICK_BROWSER` | Путь к исполняемому файлу Chromium/Chrome |

Остановить процессы через панель перед удалением данных. Для отключения аккаунта после остановки удалить его папку `.data/<платформа>`; при следующем запуске потребуется войти заново.

## Проверка

```bash
npm test
```

Тесты работают с локальными страницами и отдельными временными профилями, без обращений к аккаунтам знакомств. Проверяют выбор кнопки без отправки клика, исключение суперлайков/уже нажатой кнопки, смену карточки, ограничения настроек, защиту локального API, независимость worker от сервера панели, остановку и сохранение дневного лимита после перезапуска. Тест перехода из окна входа в фон проверяет перенос сессионной cookie и sessionStorage; для него необходим `DISPLAY`, без графической сессии этот тест пропускается.
